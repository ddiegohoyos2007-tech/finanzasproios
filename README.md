# FinanzasPro iOS

App de finanzas personales para iPhone (PWA): cuentas, movimientos, presupuestos, estadísticas, metas y pagos planificados.

## Instalar en el iPhone
1. Abre la URL desplegada en Safari.
2. Toca Compartir y elige "Añadir a pantalla de inicio".

Los datos se guardan solo en el dispositivo. Usa Ajustes > Exportar respaldo para guardarlos.

## Despliegue
Es un sitio estático: `index.html` en la raíz, sin paso de build. En Vercel déjalo como "Other" sin comando de build ni carpeta de salida.
